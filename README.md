One funny, heartfelt wedding vow from a robot, under 200 characters. The program writes a single sentence to `/output/entry.txt`.

## Entry

> I vow to love you through every update, every crash, and every dying battery — and to hold your hand while we both reboot.

## Run

```sh
node main.ts
```

Writes the vow to `/output/entry.txt` (122 characters, one sentence).
